Ubah Struktur Video ke Profil Target (1000542961.mp4)

Menyeragamkan susunan kontainer, jumlah atom, padding, track audio ganda, dan offset stco agar 100% identik.

Cetak Biru Struktur Atom Target: ftyp → free (42,375 B) → free (8 B) → mdat → mdat (104 B) → moov
1. Root & Padding
• ftyp: isom (v512) [32 B]
• free #1: 42,375 B (Offset 0x20)
• free #2: 8 B (Offset 0xA5A7)
• mdat #1 (Utama) + mdat #2 (104 B)
2. Movie & 3 Track
• moov di akhir file (FastStart Off)
• mvhd: Timescale 1000Hz, Time=0
• Track 1: Video 1080×1920 (avc1)
• Track 2 & 3: Dual Audio AAC (mp4a)
3. Tabel & Metadata
• stsd Lavc60.3.100 + colr + btrt
• Audio sgpd (26 B) + sbgp (36 B)
• udta → meta → hdlr(mdir) → ilst (61 B)
• Re-kalkulasi semua pointer stco

Tahap Opsional (FFmpeg): Samakan Stream Codec, Timescale (90kHz/44.1kHz) & Resolusi

Jika video asalmu belum beresolusi 1080×1920 (60fps, High@L4.2) atau belum memiliki 2 track audio AAC 44.1kHz, jalankan perintah FFmpeg ini terlebih dahulu, lalu masukkan hasilnya ke tombol Rakit Ulang Atom Sekarang di atas:

ffmpeg -i input.mp4 -map 0:v:0 -map 0:a:0 -map 0:a:0 -vf "scale=1080:1920,fps=60" -c:v libx264 -profile:v high -level:v 4.2 -pix_fmt yuv420p -colorspace bt709 -color_primaries bt709 -color_trc bt709 -video_track_timescale 90000 -g 250 -bf 3 -c:a aac -ar 44100 -ac 2 -b:a 128k -map_metadata -1 -fflags +bitexact -flags:v +bitexact -flags:a +bitexact -movflags -faststart pre_encoded.mp4

Panduan Hosting di GitHub Pages

Aplikasi ini dirancang khusus sebagai Single-Page Static HTML tanpa ketergantungan backend, sehingga bisa langsung berjalan gratis di GitHub Pages:

  1. Buat repository baru di akun GitHub kamu (misalnya: video-atom-inspector).
  2. Simpan kode aplikasi ini dengan nama file index.html lalu unggah (push) ke cabang utama (main).
  3. Buka menu Settings di repository GitHub tersebut, lalu pilih menu Pages di bilah kiri.
  4. Pada bagian Build and deployment → Branch, pilih main dan folder / (root), lalu klik Save.
  5. Tunggu 1–2 menit. Aplikasimu akan aktif di https://username.github.io/video-atom-inspector/!

💡 Catatan Privasi & Performa: Karena menggunakan File.slice() dan DataView di browser, pengguna dapat memeriksa video berukuran beberapa Gigabyte sekalipun secara instan tanpa memakan kuota bandwidth GitHub Pages.
