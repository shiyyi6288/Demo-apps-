SOLUSI ANTI-576p TIKTOK WEB

Mengapa Video Turun ke 576p di TikTok Web & Cara Menguncinya di 1080p

Saat unggah lewat TikTok Web, server memeriksa isi fisik di dalam mdat: (1) Codec wajib H.264 (avc1 High@L4.2) — jika masih hvc1 (HEVC) biasa, TikTok Web sering memaksa turun ke 576p; (2) Keyframe (stss) wajib terkunci setiap 250 frame (-g 250 -keyint_min 250 -sc_threshold 0) seperti pada 1000542961.mp4 (1, 251, 501, 751...); dan (3) Bitrate fisik stream di dalam mdat harus berada di kisaran 5.5 Mbps – 7.0 Mbps.

Memeriksa risiko 576p pada stream video saat ini... 
ffmpeg -i input.mp4 -map 0:v:0 -map 0:a:0? -map 0:a:0? -vf "scale=1080:1920:flags=lanczos,fps=60,format=yuv420p" -c:v libx264 -profile:v high -level:v 4.2 -b:v 6800k -maxrate 7294k -bufsize 14588k -x264-params "keyint=250:min-keyint=250:scenecut=0:bframes=3:b-adapt=0:ref=4:colorprim=bt709:transfer=bt709:colormatrix=bt709" -video_track_timescale 90000 -c:a aac -ar 44100 -ac 2 -b:a 128k -map_metadata -1 -movflags -faststart siap_rakit_1080p.mp4

Panduan Hosting di GitHub Pages

Aplikasi ini dirancang khusus sebagai Single-Page Static HTML tanpa ketergantungan backend, sehingga bisa langsung berjalan gratis di GitHub Pages:

  1. Buat repository baru di akun GitHub kamu (misalnya: video-atom-inspector).
  2. Simpan kode aplikasi ini dengan nama file index.html lalu unggah (push) ke cabang utama (main).
  3. Buka menu Settings di repository GitHub tersebut, lalu pilih menu Pages di bilah kiri.
  4. Pada bagian Build and deployment → Branch, pilih main dan folder / (root), lalu klik Save.
  5. Tunggu 1–2 menit. Aplikasimu akan aktif di https://username.github.io/video-atom-inspector/!

💡 Catatan Privasi & Performa: Karena menggunakan File.slice() dan DataView di browser, pengguna dapat memeriksa video berukuran beberapa Gigabyte sekalipun secara instan tanpa memakan kuota bandwidth GitHub Pages.
